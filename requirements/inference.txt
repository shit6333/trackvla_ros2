# --- deliberately NOT pinned to the OmTrackVLA versions ------------------
# numpy: OmTrackVLA pins 1.23.5 for habitat-sim, which has no cp312 wheel and
#        would collide with the python3-numpy that ROS 2 Jazzy links against.
#        Jazzy on Ubuntu 24.04 ships 1.26.4; the inference path uses no
#        removed numpy aliases, so we track the distro version instead.
numpy==1.26.4
#
# scipy: OmTrackVLA pins 1.13.1, but ROS 2 Jazzy's apt tree already owns
#        python3-scipy 1.11.4, which pip cannot uninstall (dpkg-installed
#        packages carry no RECORD file). The inference path imports no scipy,
#        so the distro version is used, as with numpy.
#
# opencv-python-headless: OmTrackVLA pins 4.8.1.78 (no cp312 wheel). The
#        inference path imports no cv2 at all, and ROS image conversion is
#        handled by the apt package ros-jazzy-cv-bridge, so installing a pip
#        OpenCV here would only risk an ABI conflict with cv_bridge.
